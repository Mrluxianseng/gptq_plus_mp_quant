# 先核实三阶近似，再追踪 Adam 更新：诊断实验设计

状态：仅设计，尚未运行。用户已要求先找三阶近似无收益的原因；本设计本身不启动实验，也不构成第三轮全模型实验。

## 顺序原则

先验证三阶近似本身，再检查它是否传导到 Adam 更新。若输出空间近似没有改善真实输出梯度，Adam 诊断就不是当前首要问题。

第一问：在同一量化状态和真实量化残差下，中心差分项是否补上了 Fisher 梯度与真实 KL 梯度之间的缺口？第二问：若答案为是，经过当前模块 Jacobian、坐标裁剪和 Adam 后，这项改善是否仍能降低局部下游 KL？

## 阶段 A：只验证输出空间的近似

在一个真实 refresh 快照上固定 `y0`、残差 `d`、校准样本、teacher logits、完整 FP 后缀和执行精度。对同一批输入求：

```text
g0 = ∂KL/∂y       at y0
g+ = ∂KL/∂y       at y0+d
g- = ∂KL/∂y       at y0-d
gF = REAL-Q Fisher output gradient
gc = gF + 1/2*(g+ + g- - 2*g0)
```

除了比较 `gF` 和 `gc` 对 `g+` 的余弦与相对误差，还要直接检查中心修正 `c = (g+ + g- - 2g0)/2` 是否与“Fisher 缺口” `r = g+ - gF` 对齐。记录 `cos(c,r)`、两者范数比，以及误差是否真的从 `||gF-g+||` 降为 `||gc-g+||`。公式上 `gc-g+ = c-r`，所以这个比较直接回答三阶修正是否补到了正确方向；仅看候选与目标的 cosine 不够。

为判断有限残差下的差分是否还符合三阶项的缩放规律，再用同一方向的 `αd` 计算少量尺度：

```text
c(α) = 1/2 * [g(y0+αd) + g(y0-αd) - 2g(y0)]
```

若主导项确为三阶梯度修正，`c(α)` 应近似随 `α²` 变化；比较 `c(α)/α²` 在例如 `α=0.25、0.5、1.0` 时的方向与范数是否稳定。明显漂移说明高阶有限步长项已不可忽略，不能把实际 `c(1)` 当作纯三阶项。另比较奇次中心割线 `(g(y0+αd)-g(y0-αd))/(2α)` 随 α 的变化，以检查 Fisher 对局部二阶响应 `Hd` 的近似是否已在小尺度下偏离。

此阶段是机制诊断，不是系数调参：α 只用于验证尺度律，不从结果挑一个 α 当新方法。优先只用一个 layer-4 FFN 模块、同一 batch 的小规模点位；对每个点只保留梯度摘要或短时缓存，避免持有多份 suffix 计算图。若小尺度差分出现精度噪声，再单独比较与生产一致的 BF16 路径和可行的 FP32 检查，不能把数值抖动解释成高阶效应。

判读：

* `cos(c,r)` 很低或 `||gc-g+||` 不降：当前三阶修正没有填补真实 Fisher 缺口，停止向 Adam 扩展。
* `c(α)/α²` 随 α 明显改变：实际步长下有显著高阶污染，说明此中心项不能再被解释成仅三阶修正。
* `c` 对齐 `r`、误差稳定下降且缩放规律合理：输出空间方法通过必要条件，再进入阶段 B；这仍不证明权重更新或最终 KL 会改善。
* 小 α 结果对 BF16/FP32 精度路径敏感：先处理数值可辨识性，不作近似阶数结论。

## 阶段 B：仅当阶段 A 通过，再验证 Adam 更新

把“输出空间梯度余弦更好”推进到可证伪的问题：**在 REAL-Q 的同一个量化状态和 Adam 历史状态下，Fisher＋三阶候选产生的真实权重更新，是否比原 Fisher 更新更能降低下游 KL？**

### 三个配对分支

在目标模块的一次真实 block-GD refresh 点，冻结并复制同一状态：模块权重、当前已量化前缀、待更新列范围、校准输入、标签/teacher logits、下游后缀、坐标裁剪阈值、Adam `step/exp_avg/exp_avg_sq`、学习率及 beta/epsilon。每个分支只生成一次反事实更新；分支之间不串联、不改变对方的 Adam 状态。

| 分支 | 输出侧传给该模块 VJP 的梯度 | 用途 |
|---|---|---|
| Fisher 对照 | REAL-Q 当前 `gF` | 当前基线 |
| 三阶候选 | 当前实现的 `gc` | 待判定方法 |
| KL 梯度参照 | 固定 FP 后缀上计算的 `g+` | 诊断 Adam/裁剪是否吞掉输出侧改善；不是最终量化模型上界 |

三种输出梯度都经同一个目标 block 的真实前向图对目标权重做 VJP，聚合相同样本后，才分别进入相同的权重梯度裁剪和 REAL-Q Adam 更新函数。Adam 状态必须用深拷贝，各分支以快照上的 `W` 单独计算更新。

### 在代码的哪个状态截取

取 layer 4 `mlp.gate_proj` 和 `mlp.down_proj` 的一个真实 refresh 点。优先选中段列块之后的一次 refresh，使用当时真实的待更新列切片和 Adam 矩；gate 是现有审查中修正收益最弱的模块，down_proj 则有较强局部改善，可作对照。

REAL-Q 的更新在 GPTQ 列循环内部发生（`gptq_utils/gptq_plus_utils.py` 的 `GPTQPlus.fasterquant`）；已量化列的 Adam 状态会清零，剩余列的矩可能跨 refresh 继续累积。因此：

* 快照应在真正的 `gradient_refresh_fn` 前后，对应 optimizer step 应用前；保存当前 weight、量化前缀/列范围和 Adam 状态。
* 若选首个列块之后，须确认目标切片的矩状态符合真实运行；不要把另一个块的矩或模块级全零矩套过来。
* 三分支只做反事实评估，完成后恢复原始权重与状态，让真实 GPTQ 轨迹继续时与未插诊断完全相同。

实现入口建议放在 `gptq_utils/gptq_plus_utils.py` 的 `collect_true_weight_gradient` 梯度聚合完成处，以及 `GPTQPlus.fasterquant` 中 refresh 梯度送入 optimizer 的位置附近。使用独立的 opt-in 诊断 flag，默认关闭；只对指定 layer/module/block/sample 生效。当前 `THIRD_ORDER_GRAD_AUDIT` 只看首个 batch 输出侧余弦，不保存实际权重更新，不能回答本实验问题。

### 每个分支记录什么

1. 输出侧与权重侧：`gF/gc/g+` 的范数、余弦；VJP 后原始权重梯度的范数、余弦、相对误差。
2. 裁剪后：被裁剪坐标占比、梯度范数和方向，确认逐坐标 clip 是否抹平差异。
3. Adam 后：本次真实 `ΔW` 的范数、分支间余弦、更新坐标符号分歧；同时记录输入矩状态、更新前后矩变化。不能将“原始梯度更好”当成“Adam 更新更好”。
4. 更新效果：对每个分支的 `W+ΔW` 做一次无状态前向，计算更新前/后的完整 tokenwise 下游 KL。逐样本保留 `ΔKL = KL_after - KL_before`，报告样本均值、标准误/配对区间和改善样本比例；分别报告 refresh 样本和未用于该 refresh 的 held-out 样本。

权重改变量仅应用于 REAL-Q 当时允许更新的未量化列，已量化前缀保持固定。先测固定当前 FP 后缀，以便与 `g+` 的目标严格匹配；同时记录现有真实状态下可计算的量化下游评估，区分“梯度目标本身”与“后缀不匹配”。更新评估后恢复快照，不把候选权重提交给 GPTQ 的闭式补偿/舍入。

### 如何判读

* `gc` 改善权重梯度，但 Adam 更新与 Fisher 几乎一致：检查裁剪和 Adam 归一化，改善可能在优化器映射中消失。
* `gc` 的 Adam 更新优于 Fisher，且固定 FP 后缀 held-out KL 的配对变化更低：才支持“这项更新机制在局部 work”。
* `gc` 更新比 Fisher 好，但 `g+` 参照更好：瓶颈还在输出梯度代理；需要回到 Fisher/高阶误差，而不是扩展 full run。
* 三种更新的 KL 都不降：当前状态下单步 Adam 刷新或学习率/裁剪可能是问题；不能据此说三阶项独自失败。
* 固定 FP 后缀改善、量化后缀不改善：说明部署下游状态不匹配值得单独研究；需明确这是另一个机制结论。
* 只在 refresh 样本改善、held-out 不改善：支持校准过拟合或敏感度采样问题，不支持一般性工程收益。

报告判据以 held-out 配对 `ΔKL` 为主，KL 降低为负。梯度余弦只是解释指标。单个 refresh 点只用于机制诊断；即使正向，也不能宣称全模型 KL/PPL 提升。

## 最小执行规模与保护

先在阶段 A 一个模块、一个真实残差、一个 batch 上判断公式本身。只有阶段 A 通过，才进入阶段 B 的反事实 Adam 更新；先用小批确认快照与恢复正确，再对 gate/down 各取少量 refresh 样本，并留出独立序列评估。只测诊断所需的前向/反向，不跑完整 28 层候选、不做超参扫描。每次记录输入权重 hash、量化前缀 hash、Adam 状态 hash、样本 id、后缀状态、SDPA 配置和代码 commit/hash。

安全不变量：诊断开始/结束时模型参数、GPTQ 列状态、Adam 状态逐元素一致；任一分支出现非有限值立即停止。先核实如何隔离评估权重与训练模块，避免临时写入候选权重后漏恢复。不得把局部 FP 后缀的 KL 结果写成全量化质量结论。

## 预期成本与限制

阶段 A 会在三阶分支已有 `g+、g0、g-` 之外增加少量缩放点的下游梯度反传，具体做几个 α 由最小诊断方案确定；应记录其增量时间和峰值显存。阶段 B 才额外算各分支权重 VJP、Adam 更新和无梯度评估前向。suffix 长度决定实际开销，先做单模块估测再扩展。以上只测局部状态，不足以证明层间传播或最终 PPL 改善。
